## The Applied Steps you built and what each one does

1. Source - Connect the table to the Power Query 
2. Trimmed Text - Removed all unnecessary white space from column channel
3. Capitlized each word - Capitalize each word in column channel
4. Replaced Value - removed "-" and replace them with " " in column channel
5. Filtered rows - removed all null/blank and an value not greater than 0 in column spend
6. Changed Column - changed teh data type of each column to match the appropriate data type
