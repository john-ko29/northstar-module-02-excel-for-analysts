## What is this? 

An Excel project for LinenLane Q4 2024 request by the client Beatrix Holloway. Using the data provided, I have created tables, charts and statistic analysis to explain what the data means

## What's in the folder? A short list of files and what each is.

1. linenlane-q4-2024_final.xlsx - Excel workbook containing dataset of Q4 2024 and the tables, charts, and statstic analysis
2. beatrix_holloway_memo.md - Information regarding analysis of the data found the Excel sheet and the interpreatation and recommendation.
3. module-2-ai-use-disclosure.md - AI use disclosures of AI interaction during the work on Module 2
4. dashboard_screenshot.png - screenshot of the dashboard containing KPIs, pivot tables, and charts of the Excel dataset.

## The headline findings.

4 produced 35% of LinenLane's $4.39M in 2024 revenue, driven by more orders rather than bigger ones. Three things need action: make email subject line B the default (it converted better, with moderate confidence), handle product-related returns, which drive 56% of refund dollars ($77K), and build holiday plans around bedding and decor, which grew much higher in Q4 versus other categories.
